**Описание проекта**

Это асинхронное REST API приложение для управления базой данных фильмов, работающее на FastAPI. Применяется валидация данных и авто тестирование.

**Возможности**

CRUD операции для управления фильмами
Фильтрация/сортировка списка фильмов
Валидация данных на уровне API и БД
Асинхронная работа с БД через SQLAlchemy
Авто миграции с помощью Alembic

**Техстек**

FastAPI - веб-фреймворк для создания API
Pydantic - валидация данных
SQLAlchemy - асинхронная ORM для работы с БД
SQLite - упрощенная БД для разработки
aiosqlite - асинхронный драйвер для SQLite
Alembic - инструмент для миграций БД
pytest - фреймворк для тестов

**Старт**
1. Клонирование репозитория
git clone https://github.com/Arsf747/MovieAPI.git
2. Установка зависимостей
pip install -r requirements.txt
3. Применение миграций
alembic upgrade head
4. Запуск приложения
uvicorn src.main:app --reload

**Эндпоинты**

GET	/ - Проверка состояния API
GET	/movies/ - Получить список фильмов
GET	/movies/{id} - Получить фильм по ID
POST	/movies/ - Создать новый фильм
PUT	/movies/{id} - Полностью обновить фильм
PATCH	/movies/{id} - Частично обновить фильм
DELETE	/movies/{id} - Удалить фильм

**Фильтрация и сортировка**

Параметры для фильтрации списка фильмов:
year_min - минимальный год выпуска
year_max - максимальный год выпуска
min_rating - минимальный рейтинг
order_by - сортировка (по параметрам: title, -title, year, -year, rating, -rating)
limit - количество записей (максимум 100)
offset - смещение для пагинации
Пример запроса: GET /movies/?year_min=2007&min_rating=10.0&order_by=-rating&limit=25

**Модель данных**

Фильм (movie)
id (int) - идентификатор
title (str) - название фильма (2-100 символов)
genre (str) - жанр (2-100 символов)
rating (float) - рейтинг от 0.0 до 10.0
year (int) - год выпуска (от 1888 до текущего года)


**Ограничения БД**
Рейтинг должен быть в промежутке от 0 до 10
Год выпуска не может быть раньше 1888 (до изобретения фильмов)
Название и жанр не могут быть пустыми и состоять из 1 символа
